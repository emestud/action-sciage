# Action Sciage — Trilingual Website (FR / EN / DE)

Official trilingual showcase and technical quote platform for **Action Sciage** (SARL, Wittenheim — Alsace, France), led by **Lucas Gaidella**.

> *« Refaire le monde avec des scies ! »*

## Highlights

- **Designed with Google Stitch MCP** (`#E6007E` Electric Saw Pink, `#F8C9DF` Rose Mist, `#0E1013` Obsidian Concrete, `#F5F5F2` Raw Concrete; `Space Grotesk`, `Inter`, `JetBrains Mono`).
- **Smart Pink Diamond-Saw Animations:** GPU-composited hero kerf sweep reveal, scroll-driven sticky header blade tracker, `3.5deg` laser-cut section dividers, and reduced-motion accessibility support.
- **Full Trilingual Architecture (20 HTML pages):**
  - **French (`/fr`)**: Accueil, Prestations, Réalisations, L'Entreprise, Contact & Devis, Mentions légales
  - **English (`/en`)**: Home, Services, Projects, Company, Contact & Quote, Legal
  - **German (`/de`)**: Startseite, Leistungen, Referenzen, Unternehmen, Kontakt & Angebot, Impressum
- **Zero-Build Static Vercel Deployment:** `cleanUrls: true`, legacy WordPress `301` redirects, multi-domain routing (`actionsciage.com`, `action-sciage.fr`, `action-sciage.com`), XML `hreflang` sitemap, and Schema.org structured data.
